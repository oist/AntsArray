# Detection checks

Only detection/QC tools remain here:

- `tag_detection_spatial.py`: inspect tag-detection coverage in space.
- `tag_detection_replay.py`: replay selected tag detections.
- `validate_aruco_lossless_camera.py`: validate ArUco detection on camera video.

Behavioral analysis lives in
[`../eigenposture_interactive.py`](../eigenposture_interactive.py). Older
exploratory analyses have been removed; committed versions remain in Git history.

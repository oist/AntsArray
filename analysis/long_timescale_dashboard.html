Recording coverage and how to read these plots

Calendar plots show actual observation dates. A recording name such as 20260729 is the source directory date, not necessarily the date of its tracked window. Missing observations remain unknown. Workers are joined by colony side and tag ID; cluster numbers are not assumed to match across recordings. These are within-colony diagnostics, not independent-colony replication or evidence of a causal time effect.

Does the same ant change over time?

The default view includes every observed ant and recording bin. The optional shared-clock view compares the same hours in each recording. Gray lines follow individual ants; the colored line is their mean. Horizontal positions are actual recording centers, so gaps between recordings are preserved. Connecting lines summarize observed endpoints; they do not fill unrecorded behavior.

Individual task allocation across recordings

These views extend the single-dataset grid occupancy plots for the same ant across all recording dates. Counts and durations use the existing completed colony–outside–colony trips. Trip rates use observed position hours. Unknown trip analysis is blank; an analyzed ant with no completed trips has a zero count.

Does this ant’s daily behavior profile change?

Colors show deviations from this ant’s own average for each behavior, scaled by that behavior’s variation across observed days. Hover for the original value and observation hours. Light/dark views help separate daily rhythms from changes between days. Missing days stay blank.

Spatial presence across all recordings

Whole-recording occupancy maps reuse existing grids and give each tracked ant equal weight after pooling its blocks. These maps are descriptive and are not clock-matched. They show the complete tracked cohort, regardless of the individual-ant filter above. Cyan outlines come from panorama annotations.
